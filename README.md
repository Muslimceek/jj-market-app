# JJ Market — приложение покупателя (демо по записи экрана 25.11.2026)

Мобильное веб-приложение (React + Vite + TypeScript), повторяет приложение JJ Market:
заставка → онбординг (3 слайда) → вход (можно «Atla») → вкладки Ana Sayfa / Kategori / Favoriler / Sepet / Profil.

**Данные настоящие** — публичный API api.jjmarket.kz: 363 товара с фото, ценами в ₸, скидками,
цветами/размерами и остатками, описаниями и характеристиками; дерево категорий с картинками и количеством;
фильтры (марки, размеры, цвета, сезон…); баннер. Обновить каталог:

```
npm run data
```

## Запуск
```
npm install
npm run dev
```

## Демо-вход
- логин **admin**, пароль **admin** (вкладка «Telefon Numarası» или «E-posta»);
- «Apple ile Giriş» / «Google ile Giriş» — демо-вход;
- регистрация и «SMS koduyla giriş yap» — код **1234**.

## Что есть
Главная (адрес, поиск, фильтр, баннер, категории-чипсы, Önerileriniz, Popüler Ürünler, Yeni Gelenler),
каталог и подкатегории, списки с сортировкой (7 вариантов) и фильтрами, поиск по названию на всех языках и по коду,
карточка (галерея, цвет, размеры с количеством, таблица размеров, «Seçim yardımı», характеристики, описание, похожие),
избранное, корзина (выбор, количество, адрес, Kaspi Pay / карта / Apple Pay / Google Pay, оформление),
профиль (редактирование, адреса, история заказов и детали, акции, уведомления, AI-ассистент, страна и валюта,
поддержка с FAQ, настройки, язык TR / RU / KZ, оферта, выход).

Заказы, корзина, адреса и аккаунты хранятся только в этом браузере (localStorage). Оплата не проводится.

## Файлы
- `scripts/fetch_catalog.py` — выгрузка каталога → `public/data/catalog.json` и `public/data/img/`
- `public/assets/` — мокапы онбординга и плитки «Favoriler» / «İndirim», вырезанные из записи
- `src/App.tsx` навигация · `src/store.tsx` данные и состояние · `src/i18n.ts` тексты TR/RU/KZ
- `src/Auth.tsx` `src/Home.tsx` `src/Catalog.tsx` `src/ProductPage.tsx` `src/Cart.tsx` `src/Profile.tsx` — экраны
